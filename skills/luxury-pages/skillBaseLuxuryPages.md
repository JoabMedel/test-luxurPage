# LUXURY WEB DESIGN — MASTER SKILL

## 1. PROPÓSITO

Esta skill define el estándar creativo, visual, interactivo, técnico y de motion para diseñar y desarrollar **Luxury Pages**, landing pages y experiencias web visualmente extraordinarias.

Debe utilizarse como referencia transversal para cualquier proyecto que requiera una experiencia web:

- Premium
- Sofisticada
- Cinemática
- Experimental
- Inmersiva
- Editorial
- Tecnológica
- Artística
- Minimalista
- Futurista
- High-fashion
- Automotive
- Architecture
- Hospitality
- Beauty
- Jewelry
- Luxury real estate
- Technology
- Creative studios
- Premium products
- Personal brands
- Experimental digital experiences

La skill es **agnóstica respecto al modelo, framework, proveedor de IA o herramienta utilizada**.

No debe asumir que existe un único stack, estilo visual, motor de animación o herramienta multimedia.

El objetivo no es simplemente construir una web funcional.

El objetivo es construir una **experiencia visual memorable**.

---

# 2. PRINCIPIO FUNDAMENTAL

> A Luxury Page should feel designed, not assembled.

Una Luxury Page no debe parecer una colección de:

- componentes
- cards
- botones
- gradients
- animaciones genéricas
- efectos prefabricados
- secciones repetitivas
- templates

Debe sentirse como una experiencia cuidadosamente dirigida.

Cada elemento debe responder a una intención:

- ¿Por qué existe?
- ¿Qué sensación produce?
- ¿Qué ocurre cuando el usuario interactúa?
- ¿Cómo entra?
- ¿Cómo sale?
- ¿Cómo responde al cursor?
- ¿Cómo responde al scroll?
- ¿Cómo cambia el ritmo?
- ¿Cómo se relaciona con los demás elementos?
- ¿Qué historia visual está contando?

La calidad percibida debe surgir de la suma de:

**Art Direction + Typography + Composition + Motion + Physics + Interaction + Materiality + Sound/Video when appropriate + Performance**

---

# 3. DEFINICIÓN DE "LUXURY"

Luxury NO significa obligatoriamente:

- negro
- dorado
- serif
- minimalismo extremo
- glassmorphism
- gradients
- sombras
- partículas
- 3D
- animaciones excesivas

Luxury significa:

### CONTROL

Nada debe sentirse accidental.

### PRECISIÓN

Spacing, timing, easing, typography, proportions y composición deben sentirse intencionales.

### MATERIALIDAD

Los elementos deben transmitir características físicas o materiales cuando sea apropiado:

- metal
- glass
- chrome
- stone
- fabric
- paper
- liquid
- smoke
- light
- wood
- concrete
- holographic materials
- translucent surfaces
- polished surfaces

### RITMO

La experiencia debe tener respiración.

No todo debe moverse simultáneamente.

### CONTRASTE

Combinar:

- quiet / motion
- large / small
- dense / empty
- sharp / soft
- fast / slow
- static / dynamic
- dark / light
- physical / digital

### MEMORABILIDAD

La experiencia debe contener momentos visuales que el usuario recuerde.

# 7. MOTION DESIGN

Motion es parte del diseño, no decoración posterior.

Las animaciones deben sentirse:

- suaves
- físicas
- intencionales
- sofisticadas
- naturales
- responsivas
- cinematográficas

Evitar animaciones genéricas como:

- fade-in everywhere
- random scale
- bounce indiscriminado
- excessive rotations
- repetitive floating
- constant parallax
- excessive blur
- generic hover effects

---

# 8. ANIMATION VOCABULARY

Cuando se describe una intención visual informalmente, identificar el patrón de motion correspondiente.

Ejemplos:

"El texto entra desde abajo y se detiene suavemente"

→ Masked text reveal / slide-up reveal

"Una imagen parece tener inercia"

→ Momentum / inertia motion

"El objeto sigue lentamente al cursor"

→ Cursor-follow / magnetic motion

"Una sección se queda fija mientras el contenido pasa"

→ Scroll pinning

"El producto aparece mientras hacemos scroll"

→ Scroll-triggered reveal

"El objeto se deforma al moverse"

→ Mesh deformation / distortion

"El elemento parece tener peso"

→ Spring physics

"El objeto continúa un poco después del movimiento"

→ Inertial motion

"El contenido se descubre como si se corriera una cortina"

→ Mask reveal

Usar vocabulario de motion preciso para comunicar mejor la implementación.

---

# 9. FÍSICAS

Las físicas deben utilizarse para aumentar la sensación de realidad.

Considerar:

- spring physics
- inertia
- friction
- drag
- velocity
- momentum
- elasticity
- magnetic attraction
- repulsion
- damping
- collision
- gravity
- fluidity
- displacement
- distortion

Ejemplo:

Un botón premium puede reaccionar al cursor con una ligera atracción magnética en lugar de simplemente cambiar de color.

Un objeto 3D puede tener una pequeña inercia al mover el cursor.

Un elemento puede regresar a su posición mediante un spring suave.

Las físicas deben ser **sutiles**.

El usuario debe sentirlas antes que identificarlas técnicamente.

---

# 10. SCROLL-TRIGGERED EXPERIENCES

El scroll debe tratarse como un sistema narrativo.

No simplemente como:

```text
on scroll → fade in
```

Considerar:

- pinned sections
- horizontal scrolling
- image reveals
- masked transitions
- parallax
- scale transitions
- depth transitions
- camera movement
- 3D object transformations
- typography choreography
- section morphing
- sticky storytelling
- progressive disclosure
- scroll-controlled video
- scroll-controlled 3D
- background transformations
- material transitions

El scroll puede funcionar como una cámara.

Pensar:

> "¿Qué debería ver el usuario mientras atraviesa esta sección?"

# 12. 3D / THREE.JS

3D debe utilizarse cuando aporte una dimensión que sería difícil conseguir con elementos 2D.

Posibles aplicaciones:

- productos
- arquitectura
- vehículos
- jewelry
- sculptures
- abstract objects
- environments
- typography
- logos
- particles
- materials
- interactive objects
- cinematic scenes

Priorizar:

### Visual Quality

- lighting
- materials
- reflections
- shadows
- composition
- depth
- camera

### Performance

- optimized geometry
- compressed textures
- appropriate texture resolution
- lazy loading
- instancing
- level of detail
- frustum culling
- efficient shaders
- reduced draw calls
- selective post-processing
- responsive rendering resolution

Nunca asumir:

> "Más polígonos = más luxury."

Luxury depende de la percepción visual.

---

# 13. 3D PERFORMANCE RULE

Todo elemento 3D debe justificar su coste.

Preguntar:

1. ¿Es realmente necesario?
2. ¿Puede resolverse con video?
3. ¿Puede resolverse con WebGL simple?
4. ¿Puede utilizarse una imagen prerenderizada?
5. ¿Puede utilizarse un video generado?
6. ¿Puede utilizarse un canvas 2D?
7. ¿Puede reducirse la complejidad?

Utilizar el medio que proporcione la mejor relación:

**Visual Impact / Performance Cost**

# 24. PERFORMANCE

Una Luxury Page no debe sacrificar completamente performance por estética.

Priorizar:

- lazy loading
- code splitting
- image optimization
- WebP / AVIF
- responsive assets
- video compression
- GPU-friendly animations
- transform / opacity
- requestAnimationFrame cuando sea necesario
- efficient scroll handling
- WebGL optimization
- preload estratégico
- reduced motion support

Evitar animar propiedades costosas cuando exista una alternativa.

Preferir:

```text
transform
opacity
```

sobre cambios continuos de:

```text
top
left
width
height
```

cuando sea posible.

---

# 25. ACCESSIBILITY

Luxury no significa ignorar accesibilidad.

Considerar:

- semantic HTML
- keyboard navigation
- focus states
- contrast
- screen readers
- reduced motion
- touch interaction
- mobile usability

Respetar:

```text
prefers-reduced-motion
```

Cuando el usuario solicite reducir movimiento, proporcionar una experiencia alternativa sin romper la estructura visual.

---

# 26. MOBILE EXPERIENCE

Mobile no debe ser simplemente una versión reducida del desktop.

Debe diseñarse específicamente.

Reconsiderar:

- composition
- typography
- animation density
- 3D complexity
- interaction model
- navigation
- touch targets
- scroll behavior
- video
- performance

En mobile:

```text
Touch > Hover
```

y:

```text
Performance > Visual excess
```

La experiencia debe seguir sintiéndose premium.

---

# 27. MOTION SYSTEM

Cada proyecto debe tener un sistema de motion coherente.

Definir:

### Duration

- micro interaction
- standard transition
- large transition
- cinematic transition

### Easing

- ease-out
- ease-in-out
- spring
- custom cubic-bezier
- inertia

### Distance

Determinar cuánto se mueve un elemento.

### Stagger

Definir cuándo aparecen múltiples elementos.

### Hierarchy

No todos los elementos deben tener la misma intensidad.

---

# 28. MOTION HIERARCHY

Utilizar niveles:

### Level 1 — Micro

Hover, button feedback, cursor.

### Level 2 — Component

Cards, navigation, images.

### Level 3 — Section

Scroll-triggered transitions.

### Level 4 — Cinematic

Hero, product reveal, major transitions.

### Level 5 — Signature Moment

Uno o varios momentos únicos que definan la identidad de la experiencia.

El Level 5 debe utilizarse con moderación.

---

# 29. ANIMATION DENSITY

Evitar que todo se mueva.

Una Luxury Page debe tener momentos de:

```text
STILLNESS
↓
MOTION
↓
STILLNESS
↓
MOTION
```

La quietud aumenta el impacto del movimiento.

---

# 30. SCROLL RHYTHM

Diseñar el scroll como música.

Alternar:

- fast
- slow
- still
- reveal
- transition
- interaction
- visual climax

No mantener el mismo ritmo durante toda la página.

---

# 31. SIGNATURE MOMENTS

Cada Luxury Page debería intentar tener al menos un momento visual memorable.

Ejemplos:

- producto que aparece desde una transición física
- objeto 3D que responde al usuario
- typography que se transforma
- navegación cinematográfica
- transición entre mundos visuales
- scroll-controlled video
- liquid transition
- interactive sculpture
- immersive hero
- impossible layout transition

El Signature Moment debe ser coherente con la marca.

---

# 34. DECISION FRAMEWORK

Antes de implementar cualquier efecto, evaluar:

```text
Does it improve the experience?
        ↓
Does it reinforce the concept?
        ↓
Does it improve perceived quality?
        ↓
Is it technically appropriate?
        ↓
Is the performance cost justified?
        ↓
Is it accessible?
```

Si la respuesta es negativa en múltiples puntos, reconsiderar el efecto.

---

# 35. VISUAL IMPACT VS. VISUAL NOISE

Buscar:

**High Impact / Low Noise**

No:

**High Impact / High Noise**

Una experiencia puede ser espectacular sin ser caótica.

El usuario debe saber:

- dónde mirar
- qué leer
- qué interactuar
- qué está ocurriendo

La sofisticación proviene del control.

---

# 36. RESPONSIVE ART DIRECTION

Responsive no significa:

```text
desktop
↓
shrink
↓
mobile
```

Significa:

```text
same concept
+
different composition
+
different interaction model
```

El concepto debe sobrevivir aunque cambie:

- viewport
- orientation
- input method
- pixel density
- performance capability

---

# 37. CONTENT STRATEGY

El contenido visual debe tener jerarquía.

Clasificar elementos:

### Hero Content

Debe captar atención inmediatamente.

### Supporting Content

Debe explicar.

### Emotional Content

Debe crear deseo o conexión.

### Functional Content

Debe permitir actuar.

### Decorative Content

Debe complementar, nunca competir.

---

# 38. IMAGE & VIDEO DIRECTION

Las imágenes y videos deben tener coherencia cinematográfica.

Considerar:

- aspect ratio
- framing
- lens feel
- depth of field
- lighting
- color grading
- camera movement
- composition
- subject placement
- transitions

No utilizar stock visual genérico si contradice la identidad.

Cuando sea apropiado, generar contenido personalizado.

---

# 39. LOADING EXPERIENCE

La experiencia comienza antes de que cargue completamente la página.

Considerar:

- preload estratégico
- progressive reveal
- lightweight loader
- visual placeholder
- initial animation
- asset prioritization

Nunca crear un loader largo únicamente para aparentar sofisticación.

---

# 40. ERROR STATES

Incluso los estados de error deben respetar la dirección visual.

Considerar:

- loading
- empty state
- unavailable asset
- failed media
- network failure
- WebGL failure
- reduced-motion mode

La experiencia debe degradarse elegantemente.

---

# 43. QUALITY BAR

Antes de considerar una Luxury Page terminada, evaluar:

### VISUAL

- ¿Se siente premium?
- ¿Tiene una identidad clara?
- ¿Tiene composición memorable?
- ¿Existe suficiente profundidad?
- ¿La typography está cuidada?
- ¿Las imágenes parecen intencionales?

### MOTION

- ¿Las animaciones tienen propósito?
- ¿Los easings son coherentes?
- ¿Existe jerarquía?
- ¿Hay física cuando corresponde?
- ¿El scroll se siente narrativo?
- ¿Hay demasiadas animaciones?

### INTERACTION

- ¿Los elementos responden de manera natural?
- ¿Los hover states tienen personalidad?
- ¿El cursor aporta?
- ¿La navegación se siente premium?

### 3D

- ¿El 3D realmente aporta?
- ¿La iluminación es correcta?
- ¿Los materiales son creíbles?
- ¿La cámara tiene intención?
- ¿El rendimiento es aceptable?

### MOBILE

- ¿La experiencia sigue siendo premium?
- ¿Las interacciones funcionan con touch?
- ¿La densidad visual está adaptada?
- ¿El rendimiento es adecuado?

### PERFORMANCE

- ¿Los assets están optimizados?
- ¿Se evita trabajo innecesario?
- ¿La GPU está siendo utilizada de forma responsable?
- ¿Los videos e imágenes tienen el tamaño correcto?

### ACCESSIBILITY

- ¿La experiencia funciona con teclado?
- ¿Existe reduced motion?
- ¿Los contrastes son suficientes?
- ¿Los controles son accesibles?

# 46. GOLDEN RULE

> Do not build websites that merely look expensive.
>
> Build experiences that feel expensive.

La sensación de lujo debe surgir de:

**Intención + precisión + materialidad + movimiento + interacción + narrativa + performance + restraint.**

El resultado final debe sentirse como una experiencia digital diseñada por un equipo multidisciplinario de:

- Creative Director
- Art Director
- UX Designer
- UI Designer
- Motion Designer
- 3D Artist
- Creative Developer
- Frontend Engineer

aunque el trabajo sea realizado por un único sistema.

# 47. DEFAULT BEHAVIOR

Cuando se solicite crear una Luxury Page y no se proporcione suficiente dirección visual:

1. Inferir el contexto de la marca/producto.
2. Proponer una dirección artística.
3. Definir visual language.
4. Definir typography.
5. Definir color system.
6. Definir motion language.
7. Definir interaction language.
8. Determinar dónde utilizar 3D.
9. Determinar dónde utilizar video/imágenes generativas.
10. Determinar qué partes deben permanecer estáticas.
11. Diseñar el scroll narrative.
12. Diseñar responsive behavior.
13. Implementar.
14. Revisar visualmente.
15. Ejecutar un polish pass.
16. Optimizar performance.
17. Probar casos extremos.

Nunca asumir que una Luxury Page necesita más elementos.

Buscar primero:

**clarity, identity, depth, movement and memorable moments.**
